# .ia_context

Contexto para desenvolvimento assistido por IA. Mantido público de propósito: mostra como a IA é conduzida neste projeto.

- `brief.md`: o que é o projeto, domínio, arquitetura e stack. Leitura obrigatória antes de qualquer sessão.
- `handoff-*.md`: registro de decisões tomadas fora do repositório, pendências e próximos passos. O mais recente prevalece.
- `plans/`: planos de execução (`<feature>-m<N>-<etapa>.plan.md`). Cada plano é o contrato de uma sessão de trabalho.

O que está aqui orienta; o que vale é o código, os testes e os ADRs em `docs/adr/`. Se algo aqui contradiz um ADR aceito, o ADR prevalece e este arquivo deve ser corrigido.
